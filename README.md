# نظام نقاط البيع وإدارة المبيعات - Soft Glass POS 🛒✨

نظام متكامل واحترافي لنقاط البيع وإدارة المبيعات، المخزون، المشتريات، المرتجعات، الأقساط، العملاء، والموردين.
مصمم بنمط **Soft Glass Neumorphism** (واجهة زجاجية شفافة بأزرار ثلاثية الأبعاد تفاعلية) مع دعم كامل للتشغيل المكتبي (Desktop EXE) عبر Electron وبدون الحاجة لإنترنت.

---

## 🚀 المميزات والوظائف الأساسية

1. **شاشة الدخول والصلاحيات (Authentication & RBAC):**
   - حساب مدير النظام (`admin` / `123`): صلاحيات كاملة، حذف المنتجات، وعرض التقارير.
   - حساب الكاشير (`cashier` / `123`): بيع سريع وإصدار فواتير، مع حجب التقارير وحذف الأصناف.

2. **شاشة نقطة البيع (POS Cashier):**
   - قارئ باركود آلي عبر أجهزة الباركود الخارجية بمنفذ USB أو البلوتوث.
   - بحث سريع بالاسم أو الرقم أو التصنيف.
   - إضافة الصنف بنقرة واحدة، التحكم بالكمية والخصومات لكل بند.
   - تعدد طرق الدفع: نقداً، بطاقة مدى/ائتمان، آجل، أو دفع متعدد (كاش + شبكة).
   - تعليق الفواتير (Hold Cart) واسترجاعها بسهولة.
   - بيع بالتقسيط مباشر من الفاتورة.

3. **الفواتير والطباعة (Thermal & A4 Invoices):**
   - دعم كامل للطباعة على طابعات الإيصالات الحرارية (80mm Thermal Receipt).
   - دعم طباعة فواتير رسمية بحجم (Standard A4).
   - رمز الاستجابة السريع (ZATCA QR Code) المعتمد للفوترة الإلكترونية.
   - حفظ وتصدير الفاتورة مباشرة بصيغة PDF عبر `jsPDF`.

4. **إدارة المنتجات والمخزون (Inventory Management):**
   - إضافة، تعديل، وحذف المنتجات.
   - رفع وتعديل صور الأصناف.
   - تنبيهات حية عند انخفاض الكمية عن حد الأمان.
   - استيراد وتصدير قائمة المنتجات من وإلى ملفات إكسل (Excel / CSV).

5. **المشتريات والمرتجعات (Purchases & Returns):**
   - شاشة مشتريات لتسجيل البضائع الواردة وزيادة المخزون وتتبع مستحقات الموردين.
   - شاشة مرتجع بيع لإرجاع الأصناف واسترداد المبالغ وإعادتها للمخزون.
   - شاشة مرتجع شراء لإرجاع البضائع التالفة للمورد وخصمها من حسابه.

6. **إدارة الأقساط ومتابعة التحصيل (Installment Tracking):**
   - جدول ومواعيد استحقاق الأقساط الشهرية.
   - تنبيهات بالأقساط المتأخرة والقادمة.
   - إرسال رسائل تذكير تلقائية عبر الواتساب والرسائل النصية SMS بنقرة واحدة.
   - تسجيل سداد الأقساط وإصدار سندات قبض وتحديث رصيد العميل.

7. **العملاء والموردين (CRM & Ledgers):**
   - كشف حساب لكل عميل ومورد وإجمالي المديونيات.
   - تصدير بيانات جهات الاتصال إلى إكسل.

8. **المصروفات اليومية والتقارير:**
   - تسجيل مصروفات المتجر والنثريات وتصنيفها.
   - تقارير مبيعات وأرباح حسب اليوم، الأسبوع، الشهر، أو المستخدم.
   - تصدير التقارير إلى Excel و PDF.

9. **قاعدة البيانات المحلية (SQLite):**
   - تعمل محلياً ومدمجة بالكامل `database.db`.
   - إمكانية تصدير واستيراد ملف قاعدة البيانات والنسخ الاحتياطي في أي وقت من شاشة الإعدادات.

## 🛠️ أوامر التشغيل والتجميع

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل الواجهة التجريبية (Web):
```bash
npm run dev
```

### 3. تشغيل التطبيق كبرنامج سطح مكتب (Desktop App):
```bash
npm run electron
```

### 4. بناء المشروع للإنتاج:
```bash
npm run build
```
